# Security policy

MTVanityKey generates private keys. If you find a problem that could weaken
those keys, leak them, or let someone else obtain them (for example in the
random number generation, the key derivation, or the API server), please
report it privately instead of opening a public issue:

* Use GitHub's **"Report a vulnerability"** button on the repository's
  Security tab (private vulnerability reporting).

Please include the version or commit, your platform and backend (CPU, Metal
or CUDA), and steps to reproduce. You should get an initial reply within a
week.
